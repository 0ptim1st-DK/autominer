## Описание

### Этот скрипт автоматизирует процесс копания в Minecraft по прямой линии. Программа использует компьютерное зрение и автоматизацию ввода для управления персонажем.
### Все проекты можно найти на **[моём сайте](https://0ptim1st-DK.github.io)**

## Возможности

### Возможности
- Автоматическое копание по прямой линии
- Обход препятствий при застревании
- есть определённые дополнительные функции

## Нюансы
- Работает только с инструментами с радиусом копания 3х3 и больше
- не обходит лаву
- есть циклы для проверки фантомных блоков и их разрушения (возможно частично устарел)
- Есть определённые недоработки
